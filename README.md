# 📊 Loan Propensity Analysis

## 🎯 Objetivo
Analisar dados de clientes para identificar padrões e fatores que influenciam a propensão à aprovação de empréstimos.

## 🧠 Contexto
Instituições financeiras utilizam dados históricos para avaliar risco de crédito e tomar decisões mais seguras. Este projeto simula essa análise com base em variáveis de perfil e comportamento do cliente.

## 🔧 Ferramentas
- Python
- Pandas
- Análise Exploratória de Dados (EDA)
- Estatística

## 📊 Análise realizada
- Distribuição de clientes por perfil
- Relação entre renda e aprovação
- Impacto de variáveis financeiras
- Identificação de padrões de comportamento

## 🔍 Insights
- Perfis com maior renda apresentam maior probabilidade de aprovação
- Algumas variáveis têm forte influência no risco de crédito
- Possibilidade de segmentação de clientes com base em comportamento

## 📈 Resultado
Transformação de dados em insights relevantes para apoio à tomada de decisão em concessão de crédito.
